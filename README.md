# Meal Planning and Recipe Management Web Application

This is my CW2 for COM661 (Full-stack Strategies and Development).

## Features
- Recipe CRUD (Create, Read, Update, Delete)
- Meal planning system
- Nutrition tracker (BMR calculation)
- Calories, protein, carbs tracking
- High-protein recipe filtering
- Admin and user roles
- Responsive dashboard UI

## Technologies
- Angular (Frontend)
- Flask (Backend)
- MongoDB (Database)

## How to Run

1. Install dependencies:
npm install

2. Run the app:
ng serve

3. Open:
http://localhost:4200
